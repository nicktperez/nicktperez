## Featured projects

### [Evolutionary Route Optimizer](https://github.com/nicktperez/evolutionary-route-optimizer)

An interactive operations-research project that combines A* pathfinding with a genetic algorithm to optimize warehouse collection routes. Includes greedy and exact baselines, animated playback, reproducible experiment export, automated tests, and matching web and C++17 implementations.

**Built with:** C++17 · CMake · TypeScript · React · Vite · Vitest

### [OrbitLab](https://github.com/nicktperez/OrbitLab)

A native C++20 3D N-body gravity laboratory built as an engineering sample. It explores multiple numerical integrators, exact and Barnes–Hut gravity solvers, data-oriented and concurrent execution, deterministic testing, GPU compute, persistence, diagnostics, and performance measurement.

**Built with:** C++20 · CMake · SDL3 · Dear ImGui · Catch2 · GitHub Actions

### [MacTrace](https://github.com/nicktperez/MacTrace)

A local-first macOS endpoint activity monitor and investigation dashboard. MacTrace collects security-relevant metadata, evaluates activity with plain-language rules, correlates related alerts, and keeps analysis local and explainable.

**Built with:** Python · FastAPI · SQLite · WebSockets · pytest

### [SIEM Home Lab](https://github.com/nicktperez/siem-home-lab)

A reproducible Elastic Stack lab for log ingestion, detection engineering, alert triage, and incident documentation using controlled synthetic telemetry.

**Built with:** Elastic Stack · Filebeat · Logstash · Kibana · Docker · Python
